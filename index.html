1. Metodología Ágil: Scrum

  • Por qué Scrum: Flexibilidad ante cambios del SII.
  • Sprints de 2 semanas: Entregas continuas de valor a Nuam.
  • Fases Clave:
    • Sprint 1: BD y Backend (Bloqueador)
    • Sprint 2: Frontend e Interfaz
    • Sprint 3: Lógica y Carga Masiva

2. Arquitectura (Modelo 4+1)

  • Vista Lógica & Desarrollo: Separación en Frontend (SPA), Backend (API REST Python) y Persistencia.
  • Vista de Procesos: Flujo de validación (Ej: Formato DD-MM-AAAA).
  • Vista Física (Cloud): Alta disponibilidad con AWS EC2, RDS (PostgreSQL) y S3.

3. Modelo de Bases de Datos

Implementación de Persistencia Políglota:

  • Estructurada (PostgreSQL): Core financiero transaccional (Usuarios, Calificaciones). Integridad de datos y límite del factor = 1.0.
  • No Estructurada (MongoDB): Almacenamiento de Logs de Auditoría y errores de carga en JSON, aportando flexibilidad si cambian los formatos.

4. Seguridad (OWASP Top 10)

  • Autenticación: Tokens JWT (expiración de 30 mins).
  • Mitigación A01 (Broken Access): Validación de roles por endpoint, no solo ocultando vistas.
  • Mitigación A03 (Inyección): Uso estricto de ORM para parametrizar consultas SQL.
  • Validación: Rechazo de datos alfanuméricos en factores y manejo controlado de errores (sin Stack Traces).

5. Plan de Pruebas

  • Unitarias (PyTest): Validación matemática estricta al 8vo decimal.
  • Integración (Postman): Comunicación entre la API y la base de datos.
  • Rendimiento (JMeter): Simulación de 50 usuarios haciendo carga masiva concurrente.
  • Seguridad (OWASP ZAP): Escaneo de vulnerabilidades e intentos de inyección.
