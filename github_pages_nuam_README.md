# Proyecto Integrado - Nuam Exchange
## Mantenedor de Calificaciones Tributarias

Este repositorio contiene la presentación ejecutiva y el mockup interactivo para la Evaluación 2 de Modelamiento de Soluciones Informáticas.

### Archivos
1. `presentacion.html`: Diapositivas de arquitectura, bases de datos, y plan de pruebas.
2. `mockup.html`: Prototipo interactivo (Grilla, Filtros, Modal de Ingreso) con Dark Mode y estilos corporativos.
